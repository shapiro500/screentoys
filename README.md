# screen toys

A collection of interactive web toys, small games, and pleasantly unnecessary things to poke at, made by [Gavin Shapiro](https://www.instagram.com/shapiro500/).

Make a bunch of skeletons dance around. Split some firewood. Summon an unreasonable number of pomeranians. Some toys are puzzles, some make good company for music, and some are just here because they seemed like a good idea at the time.

**[Come play at screen.toys](https://screen.toys/)**

## Run locally

Clone or download this repository, then open a terminal in its top-level folder (the one containing `index.html`). With Python 3 installed, run:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

If your system uses `python3`, use that in place of `python`. Open [localhost:8000](http://localhost:8000/) in your browser to explore the gallery and included toys. No build step is needed. Links to Five Penguins and shapiro500 open their separate websites.

Press `Ctrl+C` in the terminal to stop the server.
